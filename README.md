# Task Manager

Kanban uslubidagi vazifalar boshqaruvi ilovasi. Vazifalarni **To Do**, **In Progress** va **Done** ustunlari orasida sudrab o'tkazish mumkin.

## Imkoniyatlar

- Vazifa qo'shish, tahrirlash va o'chirish
- Drag and drop bilan ustunlar orasida ko'chirish
- Vazifa nomi bo'yicha qidiruv
- Priority (low / medium / high) bo'yicha filter
- Dark / Light mode
- Ma'lumotlar `localStorage`da saqlanadi, sahifani yangilasangiz ham yo'qolmaydi
- Telefon va kompyuterga moslashgan dizayn

## Texnologiyalar

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- dnd-kit

## Ishga tushirish

```bash
git clone https://github.com/lola66999/task-manager.git
cd task-manager
npm install
npm run dev
```

Brauzerda `http://localhost:3000` ni oching.
